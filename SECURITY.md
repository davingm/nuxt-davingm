# Security Policy

## Versi yang Didukung

Berikut adalah versi `create-davingm-nuxt` yang saat ini mendapatkan security updates:

| Version | Status |
|---------|--------|
| `0.1.x` | Didukung |

---

## Melaporkan Kerentanan Keamanan

**Jangan** buat issue publik untuk melaporkan celah keamanan.

Jika kamu menemukan kerentanan keamanan, harap kirim laporan secara **privat** melalui salah satu cara berikut:

### Opsi 1 — GitHub Private Security Advisory (Direkomendasikan)

Gunakan fitur [GitHub Security Advisories](https://github.com/davingm/nuxt-davingm/security/advisories/new) untuk melaporkan secara privat langsung di GitHub.

### Opsi 2 — Email

Kirim detail kerentanan ke: `security@davingm.com`

---

## Apa yang Harus Disertakan dalam Laporan

Agar maintainer dapat merespons dengan cepat dan tepat, sertakan informasi berikut:

- **Deskripsi** kerentanan secara jelas
- **Langkah-langkah** untuk mereproduksi masalah
- **Versi** `create-davingm-nuxt` yang terpengaruh
- **Dampak potensial** dari kerentanan ini
- **Saran perbaikan** (jika ada)

---

## Waktu Respons

| Tahap | Target Waktu |
|-------|-------------|
| Konfirmasi penerimaan laporan | ≤ 48 jam |
| Update status investigasi | ≤ 7 hari |
| Rilis patch (jika valid) | ≤ 30 hari |

---

## Pengakuan

Kontributor yang melaporkan kerentanan valid secara bertanggung jawab akan mendapatkan pengakuan di CHANGELOG (jika diinginkan).

Terima kasih sudah membantu menjaga keamanan project ini!
