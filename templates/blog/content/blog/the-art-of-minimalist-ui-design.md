# Geist Principles: Crafting Clean, Distraction-Free Developer Portfolios

Many personal websites fall into the trap of visual clutter: excessive neon glows, erratic animations, and over-rounded containers that distract from the developer's actual achievements and code quality.

By following the **Vercel Geist & VitePress design philosophy**, you create an understated yet memorable developer persona.

## Core Rules for Minimalist UI

1. **Avoid Pitch Black & Avoid Blue Tints in Dark Mode**: Pitch black (`#000000`) creates extreme contrast fatigue, while deep blues can clash with code syntax. A neutral charcoal `#121212` offers the ideal baseline.
2. **Standardize on High-Quality Geometric Fonts**: Geist Sans and Geist Mono provide immaculate readability across retina displays and code editors.
3. **Monochrome First, Accent Sparingly**: Use color exclusively for functional feedback (e.g. status indicators, copy confirmations, subtle badges).
4. **Structured Rhythm**: Use standard 8px grid increments (`gap-4`, `p-6`, `space-y-6`) to maintain harmonic balance across all viewports.
